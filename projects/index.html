Security Vulnerability Intelligence

A defensive security platform that reads an app's npm lockfile, rebuilds the exact dependency tree (including transitive packages) and checks each version against trusted OSV advisories. The matching, KEV enrichment and scoring stay deterministic, and a local-first hybrid RAG pipeline (Ollama, pgvector and specialist analyst agents) is being built on top to explain each finding with cited remediation. It's built in milestones with async SQLAlchemy, Alembic migrations and CI.

System Monitor

A lightweight system observability tool that reads CPU, per-core, memory, disk and process metrics straight from /proc and statvfs(), then serves them as JSON from a multithreaded C++ server. The same server hosts a dependency-free dashboard with live history charts and a searchable, sortable list of the busiest processes. It runs with no agent, database or framework, and the parsers are unit tested.
